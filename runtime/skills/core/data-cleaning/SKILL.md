# Data cleaning

Profile schema, units, duplicates, missing-value encodings, invalid ranges, and
identifiers before changing data. Write transformations as a script or
notebook, save a new output, and log row counts before and after each step.
Never silently drop observations, coerce units, or impute values without a
documented rationale and sensitivity check.
