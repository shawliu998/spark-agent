# Peer review

Check whether the question, design, data, analysis, figures, citations, and
conclusions match. Prioritize threats to validity, leakage, missing controls,
unsupported causal language, and irreproducible steps. Cite the exact file,
table, figure, or source behind each finding. Separate required corrections from
optional improvements and never invent missing evidence.
