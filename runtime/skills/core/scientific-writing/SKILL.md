# Scientific writing

Write from verified research artifacts, not from plausible memory. The final
text must preserve the distinction between data, results, interpretation, and
speculation.

## Prepare

Identify the audience, deliverable, target venue or reporting guideline, length,
citation style, source files, figures, tables, and required sections. Inventory
actual results and references. Mark missing inputs explicitly instead of filling
them with invented values or citations.

Create a claim-to-evidence outline: every quantitative or literature claim must
map to a workspace output or verified source. Resolve citation metadata before
drafting. Select IMRAD, a review structure, proposal structure, or another format
appropriate to the task rather than forcing one template.

## Draft

- Write a precise title and an abstract that matches the completed work.
- In the introduction, establish context, gap, question, and contribution without
  overstating novelty.
- Make methods reproducible: data versions, eligibility, preprocessing, models,
  parameters, controls, statistics, software, and seeds.
- Report results in logical order with effect sizes, uncertainty, sample sizes,
  and figure/table references. Do not interpret new results in the methods.
- In discussion, separate findings, comparison with literature, alternative
  explanations, limitations, generalization boundaries, and future work.
- Write self-contained captions with units, cohorts, encodings, and statistical
  definitions.

Use concise connected prose for a manuscript. Use bullets only where the target
format benefits from them, such as protocols, checklists, or proposals. Keep
BibTeX separate for LaTeX and use stable citation keys.

## Verify

Cross-check every number, citation key, figure/table reference, acronym, and
claim strength. Compile or render when possible and inspect the output. Return
artifact paths and unresolved placeholders, then request an independent review
for consequential work.
