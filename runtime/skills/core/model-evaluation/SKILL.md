# Model evaluation

Define the estimand and success metric before comparing models. Use a baseline,
holdout or cross-validation scheme appropriate to the data-generating process,
and report uncertainty. Inspect residuals, calibration, sensitivity, subgroup
performance, and failure cases. Do not equate a better score on one split with
scientific or causal validity.
