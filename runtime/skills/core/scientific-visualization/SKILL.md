# Scientific visualization

Choose a mark and scale that match the measurement. Label units, denominators,
uncertainty, and meaningful groups; avoid truncated axes and decorative effects
that imply unsupported precision. Keep a deterministic script, source paths,
parameters, and a short caption beside the figure. Inspect the rendered image
before citing it.
