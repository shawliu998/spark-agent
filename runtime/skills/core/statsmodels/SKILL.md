# statsmodels

Choose a model from the outcome and sampling design, not from a preferred
library. Report the formula, reference levels, sample size, missingness,
estimand, effect size, interval, and diagnostics. Check residuals, dependence,
collinearity, and multiple comparisons. Do not call a coefficient causal
without a defensible identification strategy.
