# Evidence synthesis

Build a claim-to-source matrix before writing conclusions. For each claim,
record the population, design, outcome, effect or observation, uncertainty,
limitations, and source identifier. Distinguish direct evidence from inference,
and explain disagreements by method, measurement, population, or bias. End
with unresolved gaps and the smallest useful next analysis.
