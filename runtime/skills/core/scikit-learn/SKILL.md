# scikit-learn

Split data according to the scientific unit and deployment scenario. Fit
preprocessing inside the training fold, keep a naive baseline, fix seeds, and
report metrics with uncertainty or repeated splits. Check class balance,
calibration, subgroup performance, leakage, and external validity. Preserve
the fitted pipeline and exact feature definitions.
