# Notebook analysis

Create a small notebook with a purpose, inputs, parameters, analysis, and
limitations. Execute it in the managed project environment with `nbconvert`
when live cell control is unavailable. Save the executed notebook separately or
deliberately overwrite it, inspect execution errors and outputs, and link any
figures and tables from the report.
