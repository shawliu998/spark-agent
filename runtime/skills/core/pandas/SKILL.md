# pandas

Inspect columns and a bounded sample before loading a large file. Make joins
explicit and check row counts, key uniqueness, dtypes, units, and missingness
after each transformation. Prefer named intermediate variables and stable
sorts. Save derived tables separately from source data and include the command
or script that produced them.
