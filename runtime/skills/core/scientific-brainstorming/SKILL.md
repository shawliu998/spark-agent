# Scientific brainstorming

Generate competing explanations, including a null, confound, and simple
baseline. For each idea state mechanism, risky prediction, discriminating test,
controls, resources, ethical constraints, and a stopping rule. Rank ideas by
information gain, falsifiability, feasibility, and novelty. Label all proposals
as hypotheses until evidence supports them.
